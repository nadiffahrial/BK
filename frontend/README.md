# SmartCampus 3D - Frontend Web
Aplikasi Web Interaktif Denah Gedung 3D & 2D Universitas Siliwangi (React + Vite + TailwindCSS + Lucide Icons).

## 🚀 Cara Menjalankan

```bash
# 1. Masuk ke folder frontend
cd frontend

# 2. Install dependencies (jika pertama kali)
npm install

# 3. Jalankan development server
npm run dev
```

Aplikasi akan berjalan pada: `http://localhost:5173` (otomatis proxy API ke backend port 5000).
